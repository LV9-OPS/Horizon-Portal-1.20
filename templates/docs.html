01 ? WHAT IS IT?

A launcher and manager, not another mystery executable.

HZN Manager is the Horizon desktop application. It is designed to centralize the tools players need to discover, organize and launch supported Destiny modding projects without having to hunt through folders, links and Discord messages every time.

Workshop

Browse Horizon projects and their available information before installing or using them.

Library

Keep local project executables organized and launch the paths you selected yourself.

Downloads

Access Horizon-managed downloads and keep the launcher as the central entry point.

02 ? FIRST LAUNCH

From Guest to a usable local profile.

01

Install HZN Manager and open it.

02

Choose your local username during first launch.

03

The profile starts as Guest and is stored locally.

04

Redeem an HZN-CODE when you receive BETA or Creator access.

05

HZN Manager does not require Discord OAuth for this local profile flow. Redeem codes are used to grant BETA or Creator access.

03 ? LIBRARY

How launching works.

The Library is built around explicit local executable selection. HZN Manager does not need to guess where every game or modding environment is installed.

01

Select the executable you want to use.

02

HZN Manager stores the selected local path for the installation.

03

Open or launch the selected project directly from the Library.

Supported targets

Destiny 2, Dawn and SunRise are the main project targets of the manager. The launcher is intended to make switching between local installations predictable rather than relying on automatic detection.

04 ? WORKSHOP

Discover projects before touching your files.

The Workshop is the content discovery layer of Horizon Portal. Projects can expose their type, description, compatibility and update information so players can understand what they are opening before installing anything.

Weapons

Custom weapon projects and related content.

Missions & Raids

Mission imports, raid content and larger gameplay projects.

Utilities

HUD changes, tools and other utility projects.

05 ? ACCESS & REDEEM CODES

Guest, BETA and Creator.

Guest

The default local profile. Core manager functionality remains available without a special role.

BETA

A redeem code can grant BETA access and unlock the BETA theme and associated access.

Creator

Creator access unlocks creator-only areas and the Creator theme. Creator workflows are tied to Horizon Portal moderation and publication.

Codes use the HZN-CODE-XXXXXXXX format. They are redeemed from the manager and associated with the local installation.

06 ? THEMES

Change the interface without changing the workflow.

HZN Manager includes a theme system with Horizon and Destiny-inspired visual directions. Standard themes include Destiny 2, Destiny 1, Hive, Cabal, Fallen, Corrupted and Aria. The Vex theme is reserved for Creator access, while the BETA theme is reserved for BETA access.

09 ? TECHNICAL MODEL

What happens behind the interface.

LOCAL

Your username, selected installation paths and local profile data are kept on the machine.

API

When a valid installation credential exists, the manager can synchronize access state with the Horizon API.

WEB

The Horizon Portal website provides the Workshop, account services, downloads and creator infrastructure.

TAURI

The desktop client is built with Tauri 2 and a web-based interface packaged as a Windows application.

Offline-friendly behavior

If the Horizon API is unavailable, the manager can remain usable in Guest mode. Network-dependent access synchronization and redeem operations require the API to be reachable.

10 ? TROUBLESHOOTING

When the computer decides to become philosophical.

Project does not launch

Open Library and verify that the selected executable is the correct file for the project you want to launch.

Access did not update

Check that the redeem code was accepted and that the manager can reach the Horizon API. Refreshing the manager can resynchronize local entitlement state.

Theme is locked

Creator and BETA themes are access-controlled. A normal Guest profile will not unlock them by merely clicking harder.
